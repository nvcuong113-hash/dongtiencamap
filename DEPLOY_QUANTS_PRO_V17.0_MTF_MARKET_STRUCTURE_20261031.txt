IMPORTANT — PRODUCTION PERSISTENCE GATE

The uploaded source ZIP also contains a different, small SQLite seed at:
  data/quants_pro.sqlite3

The seed is not the uploaded production backup. Do not replace or upload it over the production DB.

Streamlit Community Cloud does not guarantee persistence of local file storage. Before any production push/redeploy that may restart the app, migrate runtime DB to a managed persistent database or other durable external store, then verify row counts and backup/restore. Setting QUANTS_DB_PATH to another local path inside the same Community Cloud container does not make that storage durable.

No DB schema migration is included in V17.0. Do not manually run init_db or modify DB files as part of this P1 release.
